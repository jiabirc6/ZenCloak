# ZenCloak Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一个 Windows 桌面端专属指纹浏览器 ZenCloak，管理多个 CloakBrowser 持久化档案并一键启动。

**Architecture:** pywebview 桌面窗口 + FastAPI 本地 API + `core/` 业务层（profiles/fingerprint/sessions），底层使用 CloakBrowser `launch_persistent_context`。

**Tech Stack:** Python 3.12, pywebview, FastAPI, uvicorn, CloakBrowser, pytest, HTML/CSS/JS（无构建步骤）。
