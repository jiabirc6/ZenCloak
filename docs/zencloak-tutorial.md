# ZenCloak 新手使用教程

这份教程假设你第一次接触 ZenCloak，甚至第一次接触指纹浏览器。按顺序读一遍，10 分钟内就能跑起来自己的第一个档案。

## 1. ZenCloak 是什么

ZenCloak 是跑在你电脑上的一个桌面程序，底层使用 CloakBrowser 的 stealth Chromium 内核。你可以把它理解成一个“看起来非常接近正常 Chrome、并且很难被网站识别为自动化浏览器”的浏览器。

它和普通浏览器的区别：

- 普通浏览器：一个浏览器，一套身份。
- ZenCloak：一个程序，多个档案。每个档案是一套独立的浏览器身份、存户数据、指纹参数。

你不需要手写代码。所有操作都在图形界面里完成。

## 2. 第一次启动

### 2.1 打开 ZenCloak

已打包用户直接双击 `dist\ZenCloak.exe`。

首次启动需要解压依赖，通常会等待 20 秒左右，之后出现 ZenCloak 主窗口。

### 2.2 开发模式

在 PowerShell 里手动启动：

```powershell
cd E:\codex\opencode-zen
python -m zencloak
```

注意：用这种方式启动时，**不要关闭 PowerShell 窗口**，关了 ZenCloak 也会退出。

### 2.3 不要这样打开

不要直接双击 `src/zencloak/ui/index.html`。那是界面源文件，没有本地服务时它读不到你的档案，只会显示“未连接”。

## 3. 认识界面

打开后你会看到：

- 左侧：档案列表，显示每个档案的颜色、名称、指纹种子和运行状态。
- 左上：「新建档案」按钮。
- 上方：当前档案名称、状态，以及「启动」「停止」「保存」「删除」按钮。
- 中间：四个设置标签页：「基本信息」「指纹」「代理」「行为」。
- 下方：常用检测站点按钮。

第一次打开时，左侧应该已经有一个「本地档案」，这是 ZenCloak 自动创建的。

## 4. 三分钟创建第一个档案

### 第 1 步：新建档案

点击左侧上方「新建档案」。界面会自动创建并选中一个「新档案」。

### 第 2 步：改基本信息

点击「基本信息」标签页：

- 档案名称：给它起个名字，比如“工作号”“海外账号”“购物号”。
- 识别色：挑一个颜色，方便在列表里快速区分。
- 起始页：可选。填一个你希望启动后自动打开的网址。
- 备注：记录这个档案是干什么用的。

### 第 3 步：设置指纹

点击「指纹」标签页：

- 指纹种子：随机数字，相当于这个档案的“身份证”。同一个种子每次启动都是同一套设备指纹，不需要手改。
- 时区：你要模拟的地区，比如 `Asia/Shanghai`。
- 语言：比如 `zh-CN`。
- 屏幕：一般选 `1920 x 1080` 最稳妥。
- CPU 核数、设备内存：按预算选，比如 `8` 核、`16 GB`。
- User-Agent：新手直接留空，交给内核自动生成。

### 第 4 步：保存并启动

点击右上角「保存」，再点「启动」。

如果一切正常，会弹出一个真实的浏览器窗口，这个窗口现在使用的就是你刚才配置的指纹。

## 5. 每个配置项是什么意思

| 配置 | 作用 | 新手建议 |
| --- | --- | --- |
| 档案名称 | 只是你的管理标签 | 写清楚用途 |
| 指纹种子 | 决定整套设备指纹是否一致 | 自动生成，不要乱改 |
| 时区 | 网站看到你的本地时间 | 和你的目标地区一致 |
| 语言 | 浏览器语言 | 和目标地区一致 |
| 屏幕 | 屏幕分辨率 | 1920x1080 |
| CPU 核数 | `navigator.hardwareConcurrency` | 选 8 或 16 |
| 设备内存 | `navigator.deviceMemory` | 选 8 或 16 GB |
| User-Agent | 浏览器标识字符串 | 留空 |
| 类人行为 | 模拟真实鼠标键盘节奏 | 建议开启 |
| 代理 | 出口 IP | 需要换地区 IP 时才配 |

## 6. 什么时候需要代理

代理只在你需要“从另一个地区访问”或“网站按 IP 限量/封号”时才用。

在「代理」标签页：

1. 勾选「启用代理」。
2. 协议选 `HTTP` 或 `SOCKS5`。
3. 主机填代理服务器地址，比如 `proxy.example.com`。
4. 端口填代理端口，比如 `8080`。
5. 如果代理需要账号密码，填上。

新手常见错误：

- 主机和端口写反。
- 代理要密码但没填。
- 存档后忘记点「保存」。

代理密码已使用 Windows DPAPI 加密保存在本机档案文件中，请勿把 `~/.zencloak/` 目录上传到公开仓库。

## 7. 启动窗口之后怎么用

启动后弹出的浏览器窗口就是“真正在用的浏览器”：

- 正常浏览网站、登录账号、保存书签。
- 关闭浏览器窗口后，ZenCloak 面板会把这个档案标记回「已停止」。
- 下次再点「启动」，之前的 cookie、登录态、浏览器数据都还在，因为每个档案的 profile 是持久化保存的。

底部有几个检测站点按钮（BrowserScan、FingerprintJS、BrowserLeaks、Incolumitas），点击后会在已经打开的指纹浏览器里新开对应页面，方便你确认这个档案的伪装效果。如果档案还没启动，界面会提示先启动。

## 8. 档案隔离与数据备份

每个档案的数据都单独存在：

```text
~/.zencloak/
├── profiles/          # 指纹设置
└── data/              # 浏览器数据
```

想要备份某个账号，直接把 `~/.zencloak/` 拷贝一份到移动硬盘即可。恢复时放回原位。

## 9. 常见问题

**启动时出现 `Update available: cloakbrowser 0.3.31 → 0.5.6`？**

不是错误，是升级提示。当前 v146 内核免费可用；升级到最新内核可能需要 CloakBrowser 授权，暂时不用管。

**点了「启动」没反应？**

先确认没有其他 ZenCloak 实例在运行；再确认内核已安装：

```powershell
python -m cloakbrowser info
```

如果显示 `Installed: True`，再启动一次看面板右上角状态是否变成「启动中」或「运行中」。

**我不想用某个档案了？**

选中它，点右上角「删除」。删除会同时清理该档案的浏览器数据，操作前会二次确认。

**我想把所有档案重置？**

退出 ZenCloak 后删除 `~/.zencloak/` 文件夹，再启动就会恢复成第一次的全新状态。

## 10. 重要提醒

指纹浏览器不是用来做违规操作的。请只把它用于合法场景：多账号管理、地区测试、隐私隔离、自动化测试等。不要用于绕过授权、刷单、撞库等行为。
