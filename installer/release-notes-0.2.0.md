# ZenCloak 0.2.0

发布日期：2026-08-13

## 新功能

- 本地 API 增加随机访问令牌，只有桌面界面能调用；脚本调用需携带令牌
- 档案支持复制、导入、导出（JSON）
- 回收站：删除进回收站，可恢复或永久删除
- 批量启动 / 批量停止多个档案
- 浏览器界面固定中文，网页语言仍按档案指纹设置
- 面板新增 Google 翻译按钮，一键把网页翻译成中文
- 系统托盘：右下角图标，右键可显示窗口或彻底退出
- 下载文件固定保存到档案 `Downloads` 目录，工具栏一键打开
- onedir 快速启动构建配置（启动约 1-2 秒）
- GitHub Pages 独立主页与搜索收录

## 修复

- 高危路径穿越漏洞（档案 ID 可穿越到目录外读写）
- 启动后档案列表为空、接口未授权
- 关闭窗口后进程残留导致“已在运行”无法重启
- 第三方新标签页转圈（缓解，新标签统一为空白页）
- 浏览器界面语言跟随档案导致英文

## 说明

- 浏览器内点 `+` 新标签页目前显示空白页，请用客户端面板“打开网址”或地址栏输入
- 浏览器内置翻译仍受 CloakBrowser 内核限制，优先使用面板“翻译”按钮
